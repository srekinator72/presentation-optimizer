# Presentation Optimizer

Надстройка для PowerPoint на Windows и macOS: находит в презентации тяжёлые картинки,
видео и аудио и показывает, на каких они слайдах.

Автор — Варя Васильева. Здесь лежит собранная надстройка, которую PowerPoint загружает
по адресу из `manifest.xml`. Анализ идёт внутри PowerPoint на компьютере пользователя;
надстройка не отправляет содержимое презентации на сервер.

Установка — по инструкции из архива с надстройкой.
