# Presentation Optimizer

Надстройка для PowerPoint на Windows и macOS: показывает, что утяжеляет презентацию
(лишние пиксели в картинках, обрезанные области, анимированные GIF, 4K-видео, звук без
сжатия, встроенные шрифты, тяжёлые данные диаграмм, неиспользуемые файлы), где это
лежит и как исправить.

Идея и первая версия — Варя Васильева. Здесь лежат только собранные файлы, которые
PowerPoint загружает по адресу из `manifest.xml`: `app/` — рабочая версия, `app-beta/` —
бета для проверки. Анализ идёт внутри PowerPoint на компьютере пользователя; надстройка
не отправляет содержимое презентации на сервер.

Установка — по инструкции из архива с надстройкой.
